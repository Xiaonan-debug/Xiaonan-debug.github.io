  1. arXiv
    SecProbe: Adaptive Evaluation of Coding Agents on Cybersecurity Vulnerabilities
    Xiaonan Luo, Yue Huang, Kehan Guo, and 9 more authors
    arXiv preprint arXiv:2609.33763, 2026
    Abs arXiv Bib HTML PDF Website

    SecProbe is an adaptive evaluation framework for coding agents on cybersecurity vulnerabilities. It combines Item Response Theory with on-demand synthesis of repository-scale vulnerability-repair tasks, using observed performance to estimate agent ability and select or generate informative tasks. Across 353 tasks spanning six languages and 151 CWE types, nine frontier models reach at most 28.33% success, and SecProbe matches baseline ability estimates with up to 29.5% fewer tasks.

  2. arXiv
    Learning from Synthetic Data without Model Collapse in Iterative Instruction Tuning
    Xiaonan Luo, Yue Huang, Kehan Guo, and 4 more authors
    arXiv preprint arXiv:2607.17043, 2026
    Abs arXiv Bib HTML PDF

    We find that model collapse in iterative instruction tuning is a polarization of competence: using DINA-based skill diagnosis, we show that synthetic training can reinforce strong skills while degrading weakly supported ones. We propose KITE, a two-stage synthetic-data framework that couples weakness-guided candidate generation with boundary-aware uncertainty curation, enabling more stable multi-generation improvement than strong synthetic-data baselines across reasoning benchmarks.

  9. AAAI
    Better Datasets Start From RefineLab: Automatic Optimization for High-Quality Dataset Refinement
    Xiaonan Luo*, Yue Huang*, Ping He, and 1 more author
    In AAAI Conference on Artificial Intelligence, 2026
    Abs arXiv Bib HTML PDF

    RefineLab is a framework that formulates QA dataset refinement as an integer linear program, automatically selecting coverage, difficulty, and factual-consistency edits under a token budget to align datasets with explicit quality targets. Its modular refinement operators yield stable evaluation improvements on benchmarks including MMLU, GSM8K, and HumanEval.
